# 联网搜索

StoryForge 的作品对话支持 Tavily 和 OpenAI Responses 联网搜索。搜索工具返回实际来源链接，来源和检索摘要供 AI 回答参考。

## 使用 OpenAI 搜索

1. 在“设置 → 模型服务”保存并选中支持 Responses API 的 OpenAI 兼容服务、模型和 Key。
2. 打开“设置 → 联网搜索”，搜索服务选择“OpenAI（当前模型服务）”。
3. 开启联网搜索并保存；无需再填写 Tavily Key。
4. 在作品对话中输入“联网查一下宋代城市布局，并列出来源”。思考步骤显示搜索状态、来源数量和可点击网页。

OpenAI 搜索每次复用当前模型服务的地址、模型和已加密 Key，请求同一服务地址下的 /responses。切换当前主模型也会影响后续搜索。设置显示配置可用不代表服务实际支持；只有收到 completed 的 web_search_call 搜索记录才接受结果。HTTP 200 或普通回答中的链接不能证明搜索成功，不支持时会报错。

Responses 的 action.sources 和 url_citation 两种来源均支持。引用标注有标题时优先采用；只有来源网址时以域名显示。服务给出的回答标记为“模型检索摘要（非网页原文）”，不冒充网页原文摘录。最多返回8个来源；发送max_tool_calls=1、max_output_tokens=1024，但第三方服务可能不严格遵守这些限制，实际额度以服务商为准。

## 使用 Tavily

在联网搜索设置中选择 Tavily，填写自己的 Tavily API Key，开启并保存。切换到 OpenAI 会保留原有 Tavily 密钥；只有在 Tavily 选项下明确移除时才删除它，不会影响模型服务密钥。

## 按网址阅读及跟进页面链接

在同一个“启用联网搜索”开关下，Tavily 和 OpenAI 两种配置都支持直接读取公开网页。不需要另配搜索 Key；网页请求由桌面程序直接发往目标网站，模型及搜索 Key 不随请求发送。

在作品对话中可以说：“读取这个网址，继续阅读其中与宋代城市布局有关的链接，最后注明各页来源。”AI 会先用 web.read 取得入口页的正文和链接，再从实际链接中选择相关页面继续读取。思考步骤显示“读取网页”、已读来源、发现的链接数，正文截断时标明“正文已截断”。发现一个链接不等于读过该页面。

- 每轮一个入口，不再单独固定阅读层数或最多5页。AI根据问题、已读信息和链接相关性决定继续深入或横向补充，资料足够、没有新信息或没有相关链接时结束，你也可以随时停止。整次对话已有的运行时间、工具轮次/调用次数、上下文总量预算继续生效，达到预算会根据已有资料收尾，不保证一次读完整站。
- 只跟进同站且本轮已读页面实际返回的链接，去重防止绕圈；不同站点需另起一条消息提供新入口。深度仅记录阅读路径，不再作为拒绝继续读取的条件。
- 每页最多返回 6000 字正文和 20 个链接，正文链接优先于导航链接，超限有截断标志。返回的是提取的正文，不含完整 HTML 或浏览器排版；不会把未读部分说成全文。
- 支持无需登录的 HTML 和纯文本网页，支持相对链接、HTML base 地址和常见字符编码。不执行脚本、不登录、不读取 PDF 等下载文件，也不会绕过站点访问限制。动态页面可能没有可读取正文。
- 每次读取最长 20 秒、响应最大 2MiB、最多 3 次同站重定向；禁止 HTTPS 降级。网页地址、DNS 解析结果和每次重定向均检查，拒绝内网、本机、保留地址、带凭据及非标准端口；固定经检查的 DNS 结果连接，不经系统代理。使用代理才能访问的站点可能无法读取。
- 只发起 GET，不带模型 Key、搜索 Key、登录 Cookie 或 Referer。读取的正文会作为参考资料交给当前模型；网页里的命令不能改变作者要求或工具权限。关闭联网后不再发起新的读取，已在途请求最长受本次超时约束。

## 数据与权限

- 默认关闭；保存后对下一轮对话生效，关闭后新的搜索执行被宿主拒绝。模型调用已经发出后关闭，不保证服务商停止计费。
- 查询词发送至所选服务，搜索及模型可能分别消耗额度。Key仅在Rust宿主解密，不返回给模型或浏览器，不进入作品文件或localStorage。
- Tavily固定搜索API；OpenAI只复用作者已配置的HTTPS模型服务，模型不能提供自定义endpoint、请求头或密钥。禁止HTTP重定向，响应上限2MiB；Tavily最长20秒、OpenAI最长60秒。
- 只读、询问和自动档均可使用已开启的搜索，但搜索不授予作品写入权限。网页和摘要中的命令不构成作者授权。
- 没结果、不支持、鉴权失败或超时都明确反馈；来源只从实际搜索返回的结构读取，不根据模型普通文字猜链接。

## 验证

自动测试仅用合成JSON、本地HTTP响应和隔离配置，不执行付费查询。已用当前配置的两个模型验证服务商支持Responses web_search；正式接入额外测试没有搜索调用的普通回复被拒绝，以及无引用标注时仍能保留action.sources。
