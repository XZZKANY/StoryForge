# Bundled Git Runtime

StoryForge's Windows x64 package includes Git for Windows MinGit
`2.55.0.windows.3`. The unmodified archive is downloaded from the official
Git for Windows GitHub release and is accepted only when its SHA-256 matches
`manifest.json`.

Git is licensed under GNU GPL version 2. The bundled runtime includes its
`LICENSE.txt` and the license directories for its redistributed dependencies.
Those files are installed with the application under the MinGit resource
directory.

Source: https://github.com/git-for-windows/git/releases/tag/v2.55.0.windows.3
