## 2026-10-29 修订指令写了目标字数时，修订稿落在目标外就在补丁上提示（关联 #492）

- 改动：
  - 原因：作者让 AI 把一章改到某个字数（「改成 4000 字左右」），AI 交回 5999 字照样出补丁，界面看不出没达标。作者 10-29 拍板：先做字数提示，引擎算实际字数，在补丁上附「目标 X–Y / 实际 Z」；只提示、不拦稿、不重写。多章批量修订、前端按关键词猜意图、不合格就不出候选，都不做。
  - 引擎新增 `packages/engine/src/loop/reviseTargetLength.ts`（确定性，不加模型调用）：
    - 解析：「改成 / 改为 / 压到 / 压缩到 / 扩写到 / 控制在 N 字」「N 字左右 / 上下 / 前后」「约 / 大约 / 大概 N 字」「N 多字」「3600-4400 字 / 3600–4400 / 3600～4400 / 3600 到 4400 字 / 3600 字至 4400 字」「不超过 / 别超过 / 最多 N 字」「N 字以内 / 之内 / 以下」「至少 / 不少于 N 字」「N 字以上」；全角数字与标点、「四千」「四千五」「一万二」「两千五百」、「3k」「1.5 万」「三四千字」「三到四千字」「3-4k 字」；没带「字」时只认同一小句里有「字数 / 篇幅」的（「字数控制在 4000 左右」）。
    - 不当成目标：原稿字数（「从 6000 字压到 4000 字」「这章现在 6000 字左右，压到 4000 字」只认 4000）、增删量（「删掉 / 压缩 / 再加 2000 字」）、位置与现状（「写到 2000 字的时候」「在第 2000 字附近」「已经写到 6000 字了」「现在不到 3000 字」）、局部要求（「开头那段压到 300 字」「每段不超过 300 字」「标题别超过 20 字」「以后每章至少三千字」；前一小句提了开头 / 某段、本小句又明说「整章 / 全文」时仍认）。有动词的说法优先于只带「左右」的；几处说法取交集（「至少 3000 字，不超过 4000 字」→ 3000–4000），交集为空（「第一章改成 4000 字，第二章改成 3000 字」）就不提示。
    - 区间：单个数上下各一成（4000 → 3600–4400）。仓库里没有现成的单值容差常量：章纲的 `bookChapterRange` 是「最早 20 章中位数 ±20% 并取整到百位」，说的是本书基准、不是作者给的目标，没有复用；`chapterCheckProtocol` 的 0.7 / 1.3 是「严重偏离」门槛，也不是一回事。
    - 计数：复用 `chapterCheckProtocol.ts` 的 `chapterChars`（空白以外的每个字，与章节检查、章纲取样同一口径）。为了不让 kernel 反向依赖 loop，新模块放在 `loop/`。
  - `file.revise` 处理器：先看作者原话、认不出再看交给修订的那句指令；修订稿落在目标外时，`output` 与轨迹 `output_summary` 带 `length_hint`（message、target_min、target_max、actual_chars、direction、off_by），summary 末尾附提示让模型也知道。`requires_confirmation` 不动、不重试。对话循环（`agentRuntime.ts` 从同一补丁的轨迹提取）与固定修订管线（`fixedPipelines.ts`）都把它提到 `agent_result.length_hint`，和 #503 的 `truncation_warning` 同一条路。
  - 界面：`AssistantFileSuggestion` 加可选 `lengthHint`；修订横幅用提示色（`text-warning`，不是截断警告的红字、不挂 `role="alert"`）显示，不折进「说明」；旁注里带上；断线按事件表重建结果时从同一补丁 id 的 `file.revise` 轨迹取回（和截断警告共用一个回取函数）；本地恢复补丁时认这个字段。
  - 没改帧契约 `agent-ws.schema.json` 与 `contracts.ts`：`agent_result` 与轨迹 `output_summary` 本来就是开放对象，`proposed_patch` 形状没动。golden 一个字节都没变（预言机场景的作者原话和修订指令里都没有目标字数）。

- 未覆盖：
  - 解析是启发式，宁可漏也不乱报：「改得紧凑点，结尾别拖，4000 字左右」（前一小句提了结尾、本小句没说整章）、「加一段打斗，扩到 5000 字」、「这节奏太慢，……」以外的「这段时间」之类说法会漏；「把简介压到 200 字」在修订简介文件本身时也会漏。没带「字」也没「字数 / 篇幅」的数（「改成 4000」）不认。
